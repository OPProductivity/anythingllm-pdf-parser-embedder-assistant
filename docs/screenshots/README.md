# Screenshot gallery

This folder contains the 48 screenshots that were previously embedded directly
in the project README. Keeping them as repository assets makes the public
documentation self-contained and avoids a very long landing page.

The images are historical examples of the interface and associated AnythingLLM
views. They illustrate workflow states, not performance promises or a guarantee
that a current release has identical labels, themes, layouts, timing, or
AnythingLLM Desktop behavior.
